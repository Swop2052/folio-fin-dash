# Smart Expense Tracker

A modern, responsive FinTech-style expense tracker built with **HTML5, CSS3 and vanilla JavaScript**. No backend — all data is persisted in the browser's **Local Storage**.

## Features
- Dashboard: total balance, income, expenses, monthly savings
- Add / edit transactions (title, amount, category, date, type, notes) with full validation
- 10 categories (Food, Shopping, Travel, Bills, Entertainment, Education, Health, Salary, Freelancing, Others)
- Transaction list with search, category / month / type filters, edit, delete, pagination
- Charts: monthly expense bar chart + category donut chart (custom canvas rendering, zero dependencies)
- Analytics: highest expense category, monthly summary, monthly breakdown table, recent transactions
- Dark / light mode, glassmorphism UI, soft shadows, rounded cards, smooth animations
- Loading animation, empty states, toast notifications, delete confirmation
- JSON export and clear-all-data
